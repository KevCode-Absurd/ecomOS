## Execution sequence

1. Freeze a new prompt and output contract without editing past experiments. A card represents one useful task; its inseparable substeps remain together. Keep examples, warnings and principles distinct. Preserve conditions and source qualifiers.
2. Implement a folder runner that checks the approved manifest, reserves spend before each request, checkpoints each result and stops on uncertain network outcomes. Use the existing global ledger as well as a new shared folder ledger. No other folders are dispatched.
3. Extract all 52 initial groups with DeepSeek high and a 32,768 completion allowance. This is an allowance, not a target. Bind quotes locally. Keep malformed or unsupported outputs held.
4. Review coverage against every group, enqueue omitted advice and retrieve neighboring passages where needed. Continue until coverage is reviewed or the folder cap prevents another request. A source is not complete just because its first request succeeded.
5. Deduplicate repeated recommendations without discarding their separate evidence. Link task dependencies and warnings. Preserve contradictions for review; do not resolve them by majority vote.
6. Use OpenAI Terra high for difficult semantic checks and selected independent reviews. Check action support, applicability, numerical qualifications, prerequisites and missing dependencies. Keep operator safeguards separate from source-derived facts.
7. Test brand scenarios through retrieval, not hand-selected packets. Compare with a no-library baseline. Include low-volume stores, incomplete economics, contradictory advice and insufficient measurement. Require missing facts before consequential recommendations. Report coverage and regressions, not just valid JSON or quote matches.
8. Deliver a folder report: files and spans covered, candidates/held/reviewed cards, unresolved work, example agent answers, per-provider spend and the next folder estimate. Publication remains gated by review.
