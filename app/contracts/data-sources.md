# Data sources and tables (starter)

The data layer is `app/data/`. For the sample brand every table is generated by `data/generate.py` from `sample-brand/brand.json` with a fixed seed. For a real brand the same tables fill from read-only connectors in `app/connectors/`. Every table carries `brand`, a `captured_at` or `computed_at` stamp and a `source`.

| Table | Shaped like | Fills from (real brand) | Generator rule (sample brand) |
|---|---|---|---|
| `orders` | Shopify orders export: id, created_at, customer_id, line items with sku and qty, subtotal, discount, shipping, tax by jurisdiction, total, payment_method, channel, utm, status, refund, return, chargeback | Shopify | 13 months, weekly seasonality, Q4 peak, AOV around $85, 28 percent repeat |
| `customers` | Shopify customers: id, first_order_at, orders_count, total_spent, email_consent, sms_consent, state | Shopify | derived from orders |
| `sessions` | GA4 export: date, source, medium, campaign, landing_page, device, product_view, add_to_cart, checkout, purchase | GA4 | funnel rates by source, mobile 70 percent |
| `products` | Shopify products: sku, title, type, price, cost, weight, stock, images | Shopify plus a cost sheet | 40 SKUs in 5 types |
| `inventory` | stock by sku by day, inbound POs | Shopify or 3PL | sell-through by sku |
| `ad_rows` | Meta ad-level daily: campaign, ad set, ad, creative id, spend, impressions, reach, clicks, purchases, purchase_value | Meta Ads (read) | 3 campaigns, 12 ads, fatigue curves |
| `google_rows` | Google Ads daily by campaign and search term | Google Ads (read) | brand and non-brand and shopping |
| `flows`, `campaign_sends` | Klaviyo: flow, message, sends, opens, clicks, unsubscribes, order ids matched | Klaviyo | 6 flows, 8 campaigns a month |
| `tickets` | Gorgias: id, created_at, channel, reason, order_id, first_response_min, resolved_min, csat | Gorgias | reasons by share, tied to orders |
| `reviews` | site and Amazon reviews: sku, rating, text, date | Judge.me, Amazon | quoted language for avatars |
| `reversed_orders` | order_id, type (return, rto, chargeback), reason, amount, opened_at, closed_at, outcome | Shopify, gateway disputes | return 6 percent, chargeback 0.4 percent, rto null |
| `speed_runs` | the speed lab table: page, variant, run, load_ms, lcp_ms, fcp_ms, bytes, requests | `speed_lab.measure` | copied from a real run on the sample site or a fixture |
| `content_posts` | platform, date, format, hook, views, saves, clicks, matched orders | platform exports | 3 posts a week |
| `search_console` | query, page, clicks, impressions, position | Search Console | 200 queries |
| `marketplace_listings` | marketplace, asin or id, price, buy box, stock, rating, reviews | Amazon Seller | 15 listings |
| `payouts` | gateway and marketplace settlements: period, gross, fees, refunds, chargebacks, net, deposit date | Shopify Payments, Amazon | weekly |
| `claims`, `decisions`, `registry`, `contract_status` | the brand brain and memory tables | written by screens | seeded empty with a few examples |

Seed list for the rest: `agents/DATA-LAYER.md`. A screen that needs a table not here proposes it in a contract session.
