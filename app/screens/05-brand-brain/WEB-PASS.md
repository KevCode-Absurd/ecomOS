# Brand brain: web pass for round 2 and later (28 Sep 2026)

Public web only, 24 searches. Vendor pages and press releases are claims of what a tool does, not proof. Owner key: A = an agent does it. A>P = an agent drafts and a person approves. P = a person does it. Ranked by how much work each feature produces for the brand.

## 5 things none of these tools do

1. Learn voice from edits: compare each founder edit with the agent's draft, propose a voice sheet or word list change with before and after as proof.
2. Attach test history to claims and angles: won, lost or never tested, on which channel; agents prefer proven claims and mark untested ones.
3. Find contradictions between sources: site says 30-day returns, FAQ says 60, an ad says free returns; raise one conflict, rank which source wins, draft a fix per surface, show freshness per source.
4. Trace which live assets depend on each fact: when a price, claim tier or policy changes, list every affected ad, page and email and queue the fixes.
5. Remember rejected ideas with a reason and a review date so agents stop proposing them; score competitor moves against the brand's current bottleneck so they become ranked counter-proposals.

## Caveats

Features 1 and 19 come from regulated industries; a store needs a light version. Klue, Crayon and Kompyte are built for B2B sales; only site-change and battlecards carry over. Features 20 and 21 matter only for brands sold through retailers or marketplaces. Wiser and contract-renewal trackers were skipped; the rights and expiry features cover the renewal need.
