ecomOS Workflows
Draft for Kevin, 25 Sep 2026

Each agent is a new hire with a written way of working and a shelf of skills.

A workflow is the predetermined procedure for one job, the way a good person in the role would do it. A skill is a reusable step, nested so the agent picks the right sub-skill for the format, channel or platform. The Orchestrator hands a card to the owning agent with the workflow id; the agent follows the steps and loads skills as it goes.

Workflows

Every job, as a numbered procedure.

Open a workflow to read its steps: what the agent does, the skill it pulls, the tools, the output, the check, and when it stops to ask the founder.

Skill tree

Skills nest. The agent picks by the task's switches.

A parent skill holds sub-skills selected by format, channel, platform, flow type, marketplace or supplier region. Each has a SKILL.md with purpose, inputs, steps, checks and an example. Shared skills live in agents/skills and any agent may call them.
