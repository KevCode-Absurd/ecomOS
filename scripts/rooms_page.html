ecomOS Rooms
Draft for Kevin, 25 Sep 2026

Every part of the business as a screen a founder can act on alone.

A room shows one domain's numbers from the brand's own data, turns them into sentences with a cause and a size using rules in code, draws them, and puts the action button next to each one. The agent is optional: a founder or an agency person can read the room and decide. Screens are drawn in the "nothing connected yet" state, so every tile reads unavailable, the way the product will before data lands.

Data layer

The tables the rooms need, by source.

Union of every data need across the rooms. Tables used by several rooms come first in each group and are the ones to build first. Every table carries a brand key, a captured or computed stamp and a source. Windows end on the last full day. Missing stays null and shows as unavailable.

Design rules

What makes a room actionable.

Metrics

Every metric has a formula, a source table, a window and an unavailable rule. Computed in code. A founder can click any number and see how it was made.

Insights

An insight is a rule code can run, and the sentence it produces: what we saw, the size, the cause. No insight needs the model's judgement. Ranked by money or time saved.

Actions

Each insight carries the buttons for its capability: let the agent do it, send to a person, not now. The autonomy level comes from the catalogue. Decisions go to the registry with a read point.

Visuals

The chart fits the question: a fix chain for speed, a bridge for margin, a cohort grid for repeat, a heatmap for freshness. Charts the lab already proved (the filmstrip, the before-and-after chain, ad-level gallery) are marked as existing.

Not elsewhere

Each room names what the usual tools do not show, and says "also in X" where a tool already does it. The common thread: joining the brand's own orders to every channel, and measured before-and-after instead of scores.

Empty state

Before data connects, a room shows unavailable, says which connector fixes it, and offers the first action that needs no data (a baseline run, a crawl, an interview). The first insight appears the moment the first table lands.
