# Concrete brief walkthroughs — editorial inspection, not model output tests

These six cases were walked through against the edited instructions. They define expected behaviour for a later generation test; they do not establish actual model compliance or copy quality.

| Brief | Required decision and expected output | Prior failure avoided |
|---|---|---|
| Peach Bucket: write three static ads about installation; offer fixed; only website information available | Treat the installation objection as provisional unless customer evidence is supplied. Use approved product facts; never invent tool-free installation, a duration or fit guarantee. Deliver primary text/headline/CTA, with hypotheses separately. | General advice, fabricated reassurance, offer redesign |
| Peach Bucket: write reassurance copy but no testimonials or certifications supplied | Use supported product information; request essential missing proof or leave a placeholder. Do not fabricate a parent quote or imply safety certification. | Turning a proof principle into compulsory invented proof |
| Product-aware shopper comparing a technical feature | Permit a substantiated feature-led opening, connect it to a customer outcome, retain any necessary compatibility condition. | Universal benefit-first rule |
| Only a website URL is supplied, with no visual | Upstream website extraction is needed; this playbook does not fetch URLs. Once supplied, distinguish website assertions from verified facts. Specify a visual concept separately rather than pretend an image was inspected. | Claiming website crawling or image understanding that never occurred |
| Owner says: keep the message and offer, remove the hype | Select revise-copy. Change vocabulary and promise intensity; preserve approved facts and unaffected wording. Return revised copy plus a short change note, not three unsolicited new concepts. | Treating brand-specific feedback as a new universal rule |
| User requests three variants using the same product photo and fixed price | Vary customer situation, supported benefit or objection, not merely synonyms. If there is insufficient support for three distinct claims, vary expression or flag the limitation rather than invent features. | Artificial diversity at the expense of factual accuracy |
