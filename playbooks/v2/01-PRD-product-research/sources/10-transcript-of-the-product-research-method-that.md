## 3. Procedures

**A. Get Hooked (or equivalent ad-spy tool) filter and search procedure**
1. Open the ad-spy tool (source uses Get Hooked, accessed via a bundled subscription called Luxury Extras). `[verify UI]`
2. Set Location to USA.
3. Turn on "Top performing" only.
4. Cap ads-per-brand to 4, to avoid one advertiser flooding results.
5. Set Format to Video.
6. Set Status to "Currently running."
7. Set Minimum Runtime to 14 days.
8. Set Channel to Facebook.
9. Set Brand Active Ads to greater than 50.
10. Try a niche category filter first (source uses health and wellness).
11. If the niche filter returns junk or repetitive results, turn it off and search manual keywords instead (e.g. a specific symptom or condition), since categories under-include some relevant ads.
12. Scroll and evaluate candidates for hours; treat this as the actual work, not a quick pass. `[verify UI]`
13. On a candidate, check whether it can be sourced (open the seller's site, look for a near-identical item you could source elsewhere) before treating it as a real option.

**B. Native ad scouting procedure**
1. Open a general-interest news or weather site that carries a paid-content/sponsored widget block. Source names weather.com and CNN. `[web check: confirm these or comparable sites still carry native widget ad blocks]`
2. Locate the "paid content" or similar widget section on the page.
3. Refresh the widget repeatedly to rotate through new paid placements.
4. Log which health/wellness problem categories keep recurring (source's own list: neuropathy, tinnitus, bladder incontinence, hearing aids, snoring/sleep apnea, neck pain, hip and knee pain).
5. For a candidate with a traffic estimate tool showing no data, treat that as likely a new or low-traffic store, not proof of no demand.
6. Judge the underlying problem's severity and privacy sensitivity (source's example: female 60+ bladder incontinence rated as a strong problem because sufferers strongly want it solved), separately from how appealing the specific product looks.

**C. Facebook Ad Library validation procedure**
1. Set country filter to the target market (source uses USA).
2. Search the product keyword (e.g. "sleep patch").
3. Switch the media filter to Images, to surface native-style static ads.
4. Check how long matching ads have been active; treat more than about one week as a converting signal.
5. Read the overall pattern (how many advertisers, how much competition) rather than judging from a single ad. Source's own example: found only a couple of image ads for a child sleep patch and concluded it was still an open opportunity.
6. If no clean category filter exists, search manual keywords like "health" or "pain."

**D. Angle-mining procedure once a product is validated**
1. Go to the validated advertiser's full Facebook page profile.
2. Find or sort to the longest-running ad(s) on that page.
3. Identify the specific avatar being addressed (source's example: a mother worn down by a 4-year-old's bedtime battles) and the exact message framing used.
4. Build your own native ad against the same avatar and angle, executed better, rather than inventing a new angle from scratch.

## 5. Diagnostics and checks

- Check: does the candidate solve a problem felt daily, or only occasionally? Good: daily/chronic irritation (foot pain, incontinence, sleep disruption). Bad: one-off or novelty use. Next step if bad: deprioritize regardless of ad activity. [cccca902b3896e]
- Check: is the product sold in big-box retail? Good: not available there. Bad: widely available at retail. Next step if bad: treat as weaker margin/demand protection, though source gives no fallback rule if you proceed anyway. [cccca902b3896e]
- Check: in Get Hooked, does the niche-category filter return relevant results? Good: relevant, varied ads. Bad: junk or repeats. Next step if bad: turn off the category filter and search manual keywords. [67d4800441983b]
- Check: does a traffic-estimator show visits for a native-scouted store? Good (opportunity signal either way): no data can mean new/under-5,000-visits store, which the source treats as still worth pursuing, not disqualifying. Bad: source gives no explicit "bad" reading here — absence of data is explicitly treated as ambiguous, not negative. [484b2d31c6738c]
- Check: in Ad Library, after filtering to Images and a runtime of 1+ week, how many advertisers are actually running the product as native? Good (opportunity): few or no image ads found despite the problem being validated elsewhere (source's sleep-patch example). Bad (saturated): many advertisers running the same angle for a long time; source says to go deeper on research to compete rather than avoid entirely (his neuropathy example). ## 8. Mistakes the source warns about

- Scraping saturated aggregator feeds (source names Calata/AliExpress-style ripping): says "thousands" work the same feed daily, so CPMs/CPCs are high, no skill is learned, and a win cannot be replicated. [d3641c6bc6a895]
- Relying on TikTok/Instagram burner-account scrolling as a primary method: called outdated, "brain rot," and only workable with a trained eye that takes 3-6 months to build; Instagram burners are also called out as often just reposts from TikTok/AliExpress. [d3641c6bc6a895]
- Judging a niche purely by category filters in the ad-spy tool: categories can under-include real matches (his own health example), so relying only on the category filter risks missing valid candidates.
- Judging a native candidate as dead just because a traffic tool shows no data: presenter explicitly reads that as ambiguous (new/low-traffic store), not as a signal to drop it.
