# LOOP rooms: what they show that the common tools do not

Four rooms: Today, Brand brain, Experiments and memory, Reviews and reports.

**Today** ranks the pipeline break by money at stake, computed in code from the brand's own trailing history and a peer band, before any fix is proposed. Shopify Analytics, Triple Whale and Klaviyo show revenue and conversion, not a stage-level stake with a confidence read, and none net gross orders against expected RTO and COD confirmation the way an India funnel needs. For an agency, one ranked list crosses every brand on the same scale of stake and urgency; AgencyAnalytics and Whatagraph give per-client reports, not one queue. WhatsApp reply-to-approve ties a word back to a card id, which customer-facing WhatsApp tools do not do for internal decisions.

**Brand brain** tiers claims (approved, site-backed, forbidden) against founder-set red lines and flags a source conflict with the site as default winner. Guru, Slite and MangoApps flag stale pages but tier generic docs, not ecommerce claims. Marketplace listings on Amazon, Flipkart and Meesho get the same diff-and-flag treatment as the site (MAP violations, unauthorized resellers). Vendor renewals and India disclosures (grievance officer, GST fields, country of origin) sit in the same store and block a page from shipping.

**Experiments and memory** carries a brand-specific prior effect per idea, built only from this brand's own tries, kept apart from the bank's general basis. GrowthBook and Eppo run individual tests well but hold no cross-idea, cross-source brand memory. A repeated reject reason becomes a ranking weight automatically, and an overlap check flags two running tests before either's read is contaminated.

**Reviews and reports** names the one number that moved most this week and reconciles an agency's own report line by line against the metric contract, flagging window mismatches and metrics outside the brand's vocabulary. A portfolio capacity heatmap shows hours booked per person across every brand, which per-client report tools do not show.

## Hardest data to get

Per-brand hour estimates for portfolio capacity, scope-of-work terms from contracts, WhatsApp Business API access for the confirmation-to-RTO correlation, SKU-level marketplace snapshots, and the founder's own review hours for the cadence check. Each needs a new connector grant or a manual first entry; none flow from data already in the metric contract.
