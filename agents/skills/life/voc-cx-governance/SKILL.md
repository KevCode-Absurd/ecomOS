# Voice-of-customer and CX governance

## Purpose
Starts every VoC cycle from data the brand already owns, clusters open text into
named themes with quotes, keeps a standing NPS/CSAT read, and scores whether the
brand's CX approach is random, intentional or differentiated, with evidence.

## Steps
1. Pool open-text answers from closed support tickets and reviews for the period
   before writing a single new survey question.
2. Cluster the pooled text into named recurring themes with example quotes and a
   count, flagging anything new or growing this period.
3. Run or refresh the standing NPS/CSAT survey, keeping wording unchanged from
   the prior period unless a specific reason is logged.
4. Add a short, attributed staff-input summary.
5. Score CX maturity (random, intentional, differentiated) against a written
   standard, citing specific evidence.
6. Check any new customer-facing tool launched this period against the standard.
7. Route confirmed recurring themes to the specialist workflow that owns the fix.

## Checks
Owned data reviewed before surveying. Every theme has a quoted example. Every new
tool checked, none launched unchecked.

## Output
A theme-clustered report, an NPS/CSAT trend, and a CX maturity score with evidence.

## Example
"Theme: 'sizing runs small' - 22 mentions this quarter, up from 9 last quarter.
Routed to Product specialist and to the PDP copy. CX maturity: intentional (a
written standard exists and is checked), not yet differentiated."
