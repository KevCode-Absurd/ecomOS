# Hero and PDP buy-box builder

## Purpose
Build the highest-stakes, most-viewed section of any page or PDP against a fixed, tested structure instead of a blank page, and prove it fits on a real phone.

## Steps
1. Build the hero in the fixed order: proof, headline, subhead, CTA, FUD, image.
2. Write the headline as the outcome this SKU delivers, never a category label, and score it for specificity.
3. Write the subhead to explain how, not repeat the headline; cap hero body at 2-3 sentences or 3-4 bullets.
4. Show 2 verifiable proof forms above the fold and place real FUD reducers next to every CTA.
5. For a PDP: fit the fixed first-screen elements (price, proof, CTA, variant picker, delivery info) on the brand's real mobile device.
6. Place every control next to the element it changes; add subscribe-and-save only for genuinely consumable SKUs.
7. Answer what, why this one, why now, and why trust you, all above the fold.

## Checks
- Headline names an outcome, not a category.
- First-screen elements fit on the brand's real device, tested not assumed.
- Every FUD reducer traces to a real policy.

## Output
Hero copy draft, hero layout spec, and/or PDP buy-box spec, each ready for shared/claim-check.

## Example
"Headline: 'Stop refolding your shirts every morning' (outcome-specific) beats 'Premium Cotton Shirts' (category label)."
