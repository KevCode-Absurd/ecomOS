# Page spec and copy, general procedure

## Purpose
The base procedure every page-format sub-skill builds on: pick the right structure for the traffic, write in the brand's real voice, and never let an unsourced claim through.

## Steps
1. Pick the page type and section order that fits the traffic's awareness stage (see site/funnel-architecture for the routing decision itself).
2. Draft each section's copy using the brand's real voice guide and liked/disliked examples, not a generic tone.
3. Map every claim, number, saving or comparison to a specific brand-record source.
4. Note the image and asset needs per section, distinguishing real product photos from anything that needs new creative.
5. Run the draft through shared/claim-check before it leaves Site's hands.

## Checks
- Message matches the feeding ad, where one exists.
- Reading level is below tenth grade, short sentences, digits not words, no em dashes.
- Every claim traces to a source; nothing is invented.

## Output
A page spec: page type, audience/awareness stage, section order, copy per section with word counts, asset needs, compliance notes, CTA map.

## Example
"Hero claims '30-day risk-free trial' -> sourced to the returns policy page, dated 3 Sep 2026. Claim-check passed."
