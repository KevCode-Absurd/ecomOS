# Homepage, collection and navigation UX

## Purpose
Design the site's orienting layer, the homepage, menu and collection pages, to route shoppers fast, using real click data instead of a designer's guess.

## Steps
1. Build the homepage in a fixed, conversion-supportive section order that orients and routes rather than converting directly.
2. Decide collections manually or as rules (smart), matched to whether the set should update itself, and delete unused defaults.
3. Set tag discipline so every filter a shopper can select returns matching products.
4. Build the menu around how shoppers think, capped at 7 top items, reachable in 2-3 clicks, breadcrumbs on.
5. Rebuild the mega menu as a guide with bestsellers and proof at the top, not a bare category list.
6. Decide each collection page's job (browsing, deciding, buying) and lay it out accordingly, redesigning the mobile grid for the thumb zone.
7. Move a high-click, low-reach module higher, and restyle or remove a rarely clicked one, using real click-map data.

## Checks
- Every filter tested live to confirm it returns matching products.
- Every module move backed by a real click or scroll number.
- Menu reachable in 2-3 clicks by someone unfamiliar with the site.

## Output
A theme section spec, navigation and collection spec, tag taxonomy, or homepage/collection UX spec.

## Example
"Click map shows 'Bestsellers' menu item gets 3x the clicks of 'New In' but sits below it; swapped their order, to be re-measured next month."
