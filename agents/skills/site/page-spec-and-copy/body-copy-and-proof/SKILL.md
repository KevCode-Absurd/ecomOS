# Body copy, proof placement and honest urgency

## Purpose
Write the rest of the page's words and trust elements in the customer's own language, and make sure urgency and guarantees are always true, never invented pressure.

## Steps
1. Write each value prop as a benefit heading, feature as support, mined from real reviews and tickets.
2. Show how the product works in 3-4 steps ending at the outcome; build an honest comparison against 2-3 real alternatives.
3. Build the FAQ from that SKU's own tickets and negative reviews, quantifying claims with a true number where one exists.
4. Map every testimonial, badge and press quote to the one objection it answers, scattering proof through the page.
5. Check review dates for suspicious clustering before trusting a spike as real; add a post-purchase survey to keep collecting proof.
6. Use urgency and scarcity only when true and phrased as risk, never a fake count, wired to live inventory.
7. Present the guarantee as confidence, matched word-for-word to the real policy.

## Checks
- Every value prop and FAQ answer traces to a real review or ticket.
- No urgency claim without a true, current, checkable basis.
- Guarantee wording matches the policy page exactly.

## Output
Page copy draft, FAQ block, proof placement map, urgency/scarcity copy, and guarantee copy block.

## Example
"FAQ: 'Does it work on curly hair?' answered directly from a cluster of 14 real reviews mentioning curly hair, quoted and summarized honestly."
