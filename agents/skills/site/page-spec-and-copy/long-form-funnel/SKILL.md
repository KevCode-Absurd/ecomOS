# Long-form funnel page builder

## Purpose
Build the 3 long-form, multi-step page formats a brand uses to sell a considered purchase: the advertorial, the quiz, and the sales-to-upsell funnel.

## Steps
1. Gather the research base (reviews, tickets, competitor set, prior ad performance) before drafting anything.
2. For an advertorial: name the mechanism honestly, order in the proven 14-block sequence, draft with AI then scrub every fact, tighten before design.
3. For a quiz: cut every question with no clear job, test the first 3 hook questions, insert real info screens every 3-5 questions, build a results page from the shopper's own answers, route each answer to its offer.
4. For a sales funnel: build the sales page's 8 must-haves, a low-friction order page with a real order bump, and a post-purchase upsell timed at peak emotion and priced by contribution per buyer.
5. Run the draft through shared/claim-check regardless of format.

## Checks
- No invented spokesperson, testimonial, or study in any format.
- Quiz has no dead-end branch with no matching offer.
- Upsell price computed from real contribution margin, in code.

## Output
An advertorial draft plus research base, a quiz spec with branching and tracking, or a sales/order/upsell spec set.

## Example
"Quiz results page reflects the shopper's own 3 answers ('dry skin', 'sensitive', 'AM routine') and routes to the exact matching 3-step bundle, not a generic bestseller."
