# On-site personalization from real shopper data

## Purpose
Personalize the page from what a shopper actually told the site or actually did, never from an invented or generic assumption.

## Steps
1. Show the shopper's own quiz answers reflected back as a personalized progress visual.
2. Recommend a starter pack size from real quiz or consumption answers, not a generic default.
3. Update the product image to match the selected variant in real time.
4. Layer real-time intent signals (current session behaviour) into reassurance copy, not only past-browsing history.
5. Tailor PDP facts for AI-referred visitors (arriving via an AI answer engine) so they do not need to re-browse to confirm basics.
6. Branch the post-quiz email sequence by the shopper's own answers.

## Checks
- Every personalization rule traces to real data the site actually has about that shopper.
- No personalization is invented to feel more tailored than the data supports.

## Output
A personalization rule set and a developer brief to implement it.

## Example
"Shopper answered 'dry skin' + 'AM routine' in the quiz; PDP now shows 'recommended for dry skin, morning use' directly sourced from those 2 answers, not a generic tag."
