# Pre-build research and brief intake

## Purpose
Ground every new page in that specific SKU's own data, not a site-wide average, before a single word of copy is written.

## Steps
1. Pull the SKU's own funnel data and identify its weakest stage to fix first.
2. Read scroll maps mobile-first at the fold, 75%, 50% and 25% lines.
3. Watch converted-session recordings first, then rage-click sessions.
4. Mine reviews and surveys into ranked topics by frequency and intensity.
5. Read the market's awareness stage from search-trend data.
6. Write the 1-page brief: audience, pain, outcome, awareness stage, page type, triggering event.

## Checks
- Every data point traces to this SKU specifically, not a site average.
- The brief fits on one page and names a real triggering event.

## Output
A research brief and a 1-page build brief that starts the next page-building workflow.

## Example
"Weakest stage: PDP-to-cart, 61% drop at the size selector. 3-5 think-aloud tests confirm shoppers can't tell if it runs small. Brief: add a fit-confidence line above the selector."
