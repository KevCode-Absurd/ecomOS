# Partnership sourcing sweep

## Purpose
Good partnerships are found before there is any deal pressure to accept a mediocre one. This skill proactively builds a candidate list twice a year, separate from screening any specific proposal.

## Steps
1. From the avatar record, identify adjacent categories the same customer also spends in (for a jewellery brand's bride avatar: bridal makeup, wedding planners, occasion-wear).
2. Search for real, non-competitive brands in those adjacent categories serving the same avatar, checking their own positioning and customer base for genuine overlap.
3. Build the candidate list with a one-line note on why each one fits, before any specific collaboration proposal exists.

## Checks
- Every candidate serves the same avatar while competing in a genuinely different category, not a near-substitute.

## Output
`{candidate_partner_list: [{name, category, overlap_reason}]}`

## Example
Candidate: a bridal makeup artist collective serving the same wedding-season avatar, no product-category overlap, flagged for a future co-styling content collaboration.
