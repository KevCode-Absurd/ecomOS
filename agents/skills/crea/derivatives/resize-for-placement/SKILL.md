owner: crea-paid-creative-copy

invoke_when: an approved master needs every aspect-ratio and placement
  version a platform set requires
inputs: approved master creative, current platform-spec sheet
outputs: one resized, recomposed asset per required placement
---
Purpose: cover every real placement a master needs without a blind crop
losing the product, the face or the CTA in a differently shaped frame.

Steps
1. Pull the current required placement list from the naming-and-tagging
   skill's spec sheet, not an assumed standard set, since platforms add and
   drop placements.
2. For each placement, recompose rather than crop: reposition the subject and
   any text so the framing works on its own terms in that aspect ratio,
   rather than mechanically cutting the edges off the original.
3. Check every important element, the CTA, the product, a person's face,
   survives visibly in every single version; a story-vertical crop that
   clips the CTA off the bottom is a fail, not a minor tradeoff.

Checks: placement list matches the current spec sheet; no important element
lost in any version.

Output: the full set of resized, recomposed assets, one per required
placement, tagged to the master they came from.

Example: a 1:1 feed master gets a 9:16 story version with the product
recentered and the CTA moved up, not just the sides of the original cropped
away.
