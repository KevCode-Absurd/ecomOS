name: special-formats/objection-retargeting-copy
owner: crea-paid-creative-copy
version: 1
invoke_when: real customer objections need turning into bottom-funnel copy,
  the worst one addressed first, consistent across a retargeting sequence
inputs: support ticket export, review export, return reason codes, existing
  retargeting sequence
outputs: ranked objection list, objection-handling copy set
---
Purpose: answer the objection that is actually costing sales, ranked by real
frequency from the brand's own data, addressed early rather than buried in
an FAQ nobody reads before abandoning.

Steps
1. Pull the most common real objections from support tickets, reviews and
   return reason codes, ranked by how often each actually appears, not by
   which one the team assumes matters most.
2. Write one bottom-funnel line or copy block per objection, putting the
   top-ranked one early in whatever sequence or asset it appears in, rather
   than saving the biggest objection for a buried FAQ section.
3. Check every new line against the brand's existing retargeting sequence,
   so the same objection is never answered two different, contradicting
   ways in two different steps.
4. Hand the finished lines to whichever surface will actually run them: an
   ad inside CREA-W01, or an email or SMS block owned by Lifecycle.

Checks: every objection traced to a real quoted source and count; the top
objection addressed first, not last.

Output: the ranked objection list and the objection-handling copy set.

Example: "worried it won't fit my washing machine" outranks "worried about
color fading" 3-to-1 in support tickets, so the fit reassurance runs in ad
1 of the sequence, not ad 4.
