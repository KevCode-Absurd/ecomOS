Purpose: fill a marketplace's own fixed module system with real,
claim-checked content sized to its exact limits, since these templates
follow rules CREA does not control and the actual listing surface belongs to
Product and Supply.

Steps
1. Pull the marketplace's current module grid documentation, re-checked
   within the last 30 days, since these platforms update their template
   system without much notice.
2. Pick the banner, infographic and comparison-chart modules that actually
   fit this product's real differentiators; an empty module with no real
   content behind it is worse than a smaller, fully-populated grid.
3. Write copy for each chosen module inside its exact character and layout
   space, since marketplace modules rarely tolerate overflow gracefully.
4. Direct the real product photo or diagram for every visual module,
   never a redrawn product where fit or scale is the actual point being
   made.
5. Hand the finished modules to Product and Supply, who owns the actual
   marketplace listing surface and publishes them there.

Checks: grid spec checked within 30 days; real photo used for fit/scale
claims.

Output: the module selection, the copy for each, and the imagery
direction, handed off with the exact module grid slot each piece fills.

Example: a comparison-chart module states 3 real spec differences against
a stated competitor category, each claim traced to the brand's own claim
tier evidence.
