name: special-formats/product-page-to-ad
owner: crea-paid-creative-copy
version: 1
invoke_when: a live product page needs turning into a fast starting draft,
  not a finished, fully-briefed concept
inputs: live product page URL
outputs: page facts, flagged first-pass draft set
---
Purpose: get a usable starting set of ad copy and image direction out of a
live page in minutes, for a new or under-tested SKU that has not had a full
concept brief written yet.

Steps
1. Read the live page and pull its images, price and stated claims exactly
   as written, never paraphrased or improved.
2. Check every pulled claim against the brand's existing claim tiers,
   flagging (and dropping) anything the page states that is not yet backed
   in the brand record; a live page can drift ahead of what is actually
   approved to say in an ad.
3. Hand the cleared page facts to the static-creative and script-writing
   children to build a first-pass draft set from real images and real,
   cleared claims.
4. Flag the entire output clearly as first-pass and unproven, so it is
   never mistaken for a fully briefed, reference-checked concept.

Checks: pulled claims match the page exactly before clearing; output
flagged as first-pass.

Output: the page facts and a flagged first-pass draft set, ready for
CREA-W01's test-plan step.

Example: a new SKU's page claims "lasts 2x longer"; since that specific
number is not yet in the claim tiers, the draft set uses the safer, already
approved "built for daily use" line instead.
