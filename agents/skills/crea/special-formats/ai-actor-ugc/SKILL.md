Purpose: get a working cold-open video test live fast using a licensed
synthetic actor, treated with the same claim discipline as a real shoot,
since a synthetic ad cannot be caught and reshot the way a live one can.

Steps
1. Confirm the founder's approval covers this specific use; this capability
   never runs on a standing blanket approval, since each use is its own
   decision.
2. Finalize the script for a literal synthetic read: no line that depends on
   natural human ad lib or timing to land correctly.
3. Run the claim-tier check on the script before generation starts, since
   there is no easy reshoot once the video is generated.
4. Generate the finished vertical video with the licensed AI actor reading
   exactly the audited script.
5. Check the generated video's actual on-screen claims against the audited
   script word for word, since generation can occasionally drift from the
   input text.
6. Flag the finished asset as AI-actor generated in its metadata, for
   platform disclosure rules and internal tracking, before it ever reaches
   a handoff.

Checks: founder approval specific to this use; generated claims match the
audited script exactly; disclosure tag present.

Output: the draft AI-actor video, tagged as synthetic.

Example: a new SKU gets a same-day test video using a licensed AI actor
reading an audited hook, tagged as AI-actor generated before it goes to
MEDIA.
