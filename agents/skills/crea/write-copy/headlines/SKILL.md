---
name: write-copy/headlines
owner: crea-paid-creative-copy
version: 1
invoke_when: the copy needed is a short headline for a static, search or
  marketplace listing
inputs: angle brief, cleared claim list, reference image if pairing a static,
  platform character limit
outputs: ranked headline set with character counts
---
Purpose: produce a real range of headline candidates, not three near-identical
rewordings, and confirm each one fits both its space limit and the image it
runs beside.

Steps
1. Draft 10 or more candidates from the angle's dominant appeal, varying the
   specific benefit named (speed, price, comfort, status) rather than just
   rewording one phrase 10 times.
2. Where a static image is already chosen, check each candidate against it:
   the headline and the image should state one shared idea, not two competing
   claims.
3. Check every candidate's character count against the platform's current
   limit; cut or shorten anything that would truncate.
4. Rank the full set and mark the top 3 to 5 as the ones to actually test,
   with a one-line reason for the ranking.

Checks: 10+ candidates before culling; no length violation; no image-headline
mismatch; ranking reasoned, not arbitrary.

Output: the full candidate list, each with its character count, and the top
3-5 flagged for test.

Example: for a cold-brew concentrate, candidates range across speed ("coffee
in 10 seconds"), price ("75 cents a cup") and taste ("less bitter, more
buzz"), ranked by which best pairs with the chosen close-up product shot.
