---
name: make-creatives/carousel
owner: crea-paid-creative-copy
version: 1
invoke_when: format is a multi-card carousel telling a sequence, not a single
  static or video
inputs: concept brief, format-economics decision, product facts, headline/primary-text set
outputs: ordered carousel card sequence with a CTA card
---
Purpose: build a carousel that earns each swipe, using a real sequence logic,
rather than defaulting to cards just because the format exists.

Steps
1. Check that format-economics actually chose carousel because the product has
   a real sequence to show: steps of use, a size or variant range, or a
   before-to-after story. If not, send it back to static or video instead.
2. Pick the sequence logic explicitly and state it in the brief, so every card
   is built to advance that one logic, not a grab-bag of images.
3. Write one headline per card that earns the next swipe on its own, testing
   the first 2 cards as if that is all a viewer will ever see.
4. Pair each card's real product image with its headline; no card runs on a
   generic stock image with no connection to the sequence.
5. Put the offer and CTA on the final card, not mid-sequence where it gets
   skipped.
6. Read the full sequence end to end for message-match and pacing before
   handoff.

Checks: real sequence logic named; first 2 cards stand alone; CTA on the last
card.

Output: an ordered list of image-headline card pairs plus the CTA card, tagged
with the sequence logic used.

Example: a skincare routine ad uses 4 cards, one per step, ending on card 5
with the bundle price and a single CTA, rather than 5 unrelated product shots.
