# Design the meeting rhythm and facilitation guides

## Purpose
Size the meeting calendar to the team that actually exists, and hand the founder a run sheet instead of a theory of team dynamics.

## Steps
1. Design the cadence: annual reset, quarterly deep dive, weekly trading review, ad hoc, each with a stated purpose.
2. Build the visible scoreboard the weekly review runs against, using the same metric contract numbers as the finance dashboard.
3. Design how a decision cascades from the quarterly deep dive down to individual owners.
4. Prepare a structured trust, dysfunction or accountability facilitation guide as a run sheet, tied to one metric the session should move.

## Checks
- Every meeting on the cadence has a stated purpose and a metric.
- A facilitation guide is a run sheet the founder can use directly, not a summary of a framework.

## Output
The meeting cadence design, the visible scoreboard, or a facilitation run sheet.

## Example
A weekly trading review is added only after the scoreboard shows CM3 swinging more than 15 percent week to week; the cadence design states that exact trigger for why the meeting exists.
