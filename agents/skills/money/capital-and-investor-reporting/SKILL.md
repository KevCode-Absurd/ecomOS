# Assemble the data room and investor/lender reporting pack

## Purpose
Package the numbers that already exist (P&L, cash, cohort economics) into the shape a lender or investor asks for, without inventing a new deliverable.

## Steps
1. Pull the current P&L ladder, cash forecast, CAC/LTV report and cap table.
2. Assemble the data room with every document dated.
3. Produce the monthly update and check loan covenants explicitly as met or breached.
4. Produce the quarterly board deck's financial section from the same source numbers, never a separate estimate.

## Checks
- Every document in the room carries a version date.
- Covenant status is stated plainly, never implied by a number sitting near a threshold.

## Output
The current data room, the covenant compliance status, and the board deck's financial pages.

## Example
A loan covenant requires a minimum current ratio of 1.2; this month's ratio of 1.15 is stated as breached, with the cash forecast page showing the path back above 1.2.
